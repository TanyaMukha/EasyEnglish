# Flag icon sources

- `de.svg`, `es.svg`, `fr.svg`, `gb.svg`, `it.svg`, `pl.svg`, `pt.svg`, `tr.svg`, `ua.svg`, `xx.svg` —
  [flag-icons](https://github.com/lipis/flag-icons) by lipis, MIT License. No attribution required.
- `us.svg` — [Twemoji](https://github.com/twitter/twemoji) by Twitter/X, licensed under
  [CC-BY 4.0](https://creativecommons.org/licenses/by/4.0/). Replaced the flag-icons version, whose
  `<marker>`/zigzag-path technique for drawing the 50 stars failed to render as an `<img>` in
  WebView2 on Windows; Twemoji draws each star as an explicit `<path>` instead.
